# SharePoint Events Portal Project

## Organizational Context
Casa Familiar organizes multiple annual events (Fall Festival, Haunted House, Día de Muertos, etc.). These events involve high volunteer turnover in their committees. We need a standardized, secure, and automated system to manage tasks, budgets, and files while ensuring data continuity and secure offboarding.

## 👥 Stakeholders
- **Nefi Lopez**: IT Analyst / Scrum Master
- **Event Leads**: Responsible for site ownership and committee management.
- **Committee Members**: Volunteers managing tasks and logistics.
- **IT Leadership**: Oversight of security and governance.

## Main Objectives
1. **Standardization**: Use a Hub Site architecture so all event portals look and behave the same.
2. **Security**: Centralized onboarding/offboarding via M365 Groups/Entra ID.
3. **Automation**: [Low-Code] Use Site Scripts (JSON) and PnP PowerShell for 5-minute site deployment.
4. **Visibility**: Real-time dashboards on the Hub Site showing "Blocked Tasks" across all events.
5. **Continuity**: Automated rollover flows to clone critical tasks for the next year's cycle.

## Agile-Lite Approach
This project will be managed using the **Agile-Lite** framework, focusing on high-impact technical milestones and seamless handovers between event committees.
