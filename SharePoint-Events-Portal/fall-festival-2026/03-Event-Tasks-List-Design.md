# Event Tasks List Design - Fall Festival 2026

## Shared Schema

The Event Tasks list uses the **same schema** as all other Casa Familiar events. The full column definitions, category choices, progress statuses, views, and JSON formatting are documented in the shared reference:

> **See**: [[../abrazo-2026/03-Event-Tasks-List-Design.md]]

---

## Why This Is Shared

The task list design was intentionally created to be **event-agnostic**. The categories (IT/SharePoint, Logistics, Outreach, Volunteers, Budget/Finance, Communications, Committee Coordination, Post-Event) apply to every Casa Familiar event without modification.

This aligns with the project's standardization goal: all event portals use the same list schema via the Content Type Hub.
