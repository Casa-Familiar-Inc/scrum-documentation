# Scrum Documentation

This repository contains the Scrum planning and project management documentation for Casa Familiar IT projects.

## Projects

- **Salesforce Reporting & KPIs** - Centralize SS and FOC intakes
- **SharePoint Events Portal** - Standardize and automate event management
- **AppFolio to QuickBooks Integration** - Migrate financial data
- **Automation & Low-Code** - Scripts and flows to reduce administrative burden

## Structure

- `Master-Project-Board.md` - Global project status overview
- `Master-Sprint-Plan.md` - Sprint backlog and planning
- `Master-Sprint-Plan-Workload-Analysis.md` - Capacity analysis
- `Salesforce-Reporting-KPIs/` - Salesforce project documentation
- `SharePoint-Events-Portal/` - SharePoint project documentation
- `sharepoint-events/` - Technical documentation and guides
- `AppFolio-QuickBooks-Integration/` - Integration project files
- `weekly-reports/` - Weekly activity reports
